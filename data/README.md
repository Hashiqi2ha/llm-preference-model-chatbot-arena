# Data

The datasets used in this project come from the Kaggle **LLM Classification Finetuning** competition.

Due to GitHub size limits, the raw data (`train.csv`, `test.csv`, `sample_submission.csv`) are **not stored** in this repository.

To reproduce the results:

1. Download the data from Kaggle:
   - https://www.kaggle.com/competitions/llm-classification-finetuning
2. Place the files into this `data/` directory:
   - `data/train.csv`
   - `data/test.csv`
   - `data/sample_submission.csv`
3. Run the notebook `notebooks/llm_preference_baseline.ipynb`.
