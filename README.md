# LLM Preference Model on Chatbot Arena

Preference modeling project based on the Kaggle **LLM Classification Finetuning** competition.  
Given a prompt and two candidate LLM answers, the goal is to predict which answer humans prefer.

## Project Goals
- Explore human preference data from Chatbot Arena
- Build baseline and transformer-based preference models
- Analyze biases such as position and verbosity
- Provide a simple API / demo for comparing two responses
